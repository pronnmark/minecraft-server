**Windows:** download **Join-Grisch-Windows.bat** below and double-click it. If Windows says "Windows protected your PC", click **More info → Run anyway**.

**Mac:** open Terminal and paste:

```
curl -fsSL https://github.com/pronnmark/minecraft-server/releases/latest/download/join-mac.sh | sh
```

Then press **Play** in the Minecraft Launcher (the **Grisch** profile is picked) → **Multiplayer** → **Grisch**.

You need the official Minecraft Launcher, signed in and opened once. Your normal Minecraft is not changed.
